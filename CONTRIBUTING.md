# Contributing

This definition gets better when people who build, buy and attack these
systems argue with it. Here's how.

## Where to take what

- **A comment, question or objection:** start a thread in
  [Discussions](../../discussions).
- **A proposal to add, remove or change a property:** open an
  [Issue](../../issues). Say which property, what should change, and how a
  buyer would test the new version. If it can't be tested, it doesn't belong
  in the definition.
- **A wording fix, broken link or typo:** send a pull request.
- **Your own version:** fork it. It's [CC BY 4.0](LICENSE). Credit the
  original and link back.

## How versions work

- Minor versions (1.1, 1.2) only clarify wording. They never change what
  passes.
- A new property, or a stricter one, is a new major version (2.0).
- A vendor's conformance statement names the version it claims, so
  "we meet 1.x" means the same thing next year as it does today.
